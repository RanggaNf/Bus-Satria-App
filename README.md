## 📋 Deskripsi

Aplikasi Android untuk manajemen dan tracking armada bus Satria. Fitur meliputi GPS tracking, jadwal keberangkatan, manajemen penumpang, dan laporan operasional.

Project ini merupakan bagian dari portfolio pengembangan software oleh **Mohamad Rangga Nur Faizin**, mencakup berbagai bidang mulai dari Android Development, Backend Engineering, Internet of Things (IoT), Machine Learning, hingga Web Development.

## ✨ Fitur Utama

- Real-time GPS tracking
- Jadwal & rute
- Manajemen penumpang
- Laporan operasional

## 🚀 Cara Menjalankan

### Prasyarat

Pastikan Anda telah menginstall tools yang diperlukan sesuai dengan teknologi di atas.

### Instalasi

```bash
# Clone repository
git clone https://github.com/RanggaNf/Bus-Satria-App.git
cd Bus-Satria-App

# Install dependencies (sesuaikan dengan package manager)
# Untuk Android: Buka dengan Android Studio
# Untuk Python: pip install -r requirements.txt
# Untuk Web: npm install
```

### Menjalankan

```bash
# Sesuaikan dengan jenis project:
# Android: Run dari Android Studio
# Python: python main.py
# Web: npm run dev
```
